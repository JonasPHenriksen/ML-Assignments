# ML Assignments

Machine-learning assignments, one folder each, as Jupyter notebooks with the data they use.

## Data sources

The data belongs to the people who published it; it is kept here only so the notebooks run.

| Assignment | Data | Source |
|---|---|---|
| 1. Copenhagen AirBnB | `listings.csv` | [Inside Airbnb](http://insideairbnb.com/copenhagen), Copenhagen listings, licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). First-name statistics from [Danmarks Statistik](https://www.dst.dk/da/Statistik/emner/borgere/navne/navne-i-hele-befolkningen). |
| 2. Car Prices | `car_prices.xlsx` | Provided with the course. |
| 3. Candidate Test 2022 | `alldata`, `drdata`, `drq`, `electeddata`, `tv2data`, `tv2q` (.xlsx) | DR's and TV 2's candidate tests for the 2022 Danish general election, as collected at [v2022.dumdata.dk](https://v2022.dumdata.dk/) and [kwedel.github.io/kandidattest2022](https://kwedel.github.io/kandidattest2022/). The questions and answers belong to DR and TV 2. |
| 4. Mushroom foraging | `secondary_data.csv` | The Secondary Mushroom Dataset ([Kaggle copy](https://www.kaggle.com/datasets/dhinaharp/mushroom-dataset)), originally from the UCI Machine Learning Repository, licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). |
| 5. Sentiment analysis | `reviews.txt`, `labels.txt` | Provided with the course. |
| 6. Candidate Test 2022 II | the same data as assignment 3 | As assignment 3. |

The GIFs in assignment 6 are illustrations: `K-means_convergence.gif` is from
[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:K-means_convergence.gif) (author and licence on that page);
`hierarch.gif` and `1_tc8UF-h0nQqUfLC8-0uInQ.gif` came from articles on the web, and their authors were not recorded.
